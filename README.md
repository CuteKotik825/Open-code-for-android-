# PocketCode

Кодинг-агент в духе OpenCode / Claude Code / Codex, который работает **прямо на телефоне, без ПК**.
Пишешь задачу в чате, агент сам читает и правит файлы, запускает команды и работает с git.

## Что умеет (v0.1)

- Чат с агентом, который вызывает инструменты в цикле, пока задача не решена
- Потоковый вывод: ответ появляется по мере генерации
- Фоновая работа: foreground-сервис с уведомлением и кнопкой «Стоп», wake lock; агент не прерывается при сворачивании и закрытии экрана
- Уведомления, когда нужно подтверждение или агент закончил, пока приложение не на экране
- Сжатие контекста: при заполнении ~70% лимита (задаётся в настройках) старые выводы инструментов сокращаются, а ранняя часть диалога заменяется сводкой; при ошибке переполнения от API сжатие запускается само и запрос повторяется
- Сохранение сессий: автосохранение, экран «История», восстановление последней сессии при запуске
- Инструменты: `read_file`, `write_file`, `edit_file`, `list_dir`, `grep`, `bash`, `git`
- Git на чистой Java (JGit): clone, status, diff, add, commit, push, pull, log, branch, checkout
- Любая модель по API-ключу: Anthropic (Claude) или любой OpenAI-совместимый API (OpenAI, OpenRouter и т.д.)
- Подтверждение опасных действий (запись, правка, команды, git-изменения); можно отключить в настройках
- Ключи хранятся в зашифрованном хранилище приложения (EncryptedSharedPreferences)
- Рабочая папка приложения: `files/workspace`, файловые инструменты из неё не выходят

## Как собрать APK с телефона

1. Запушь изменения в `main` (или открой вкладку **Actions → Build APK → Run workflow**).
2. Дождись зелёной галочки.
3. Открой запуск, внизу в разделе **Artifacts** скачай `PocketCode-debug-apk`, распакуй zip и установи APK.

Все сборки подписаны одним ключом из `app/debug.keystore`, поэтому новая версия ставится поверх старой с сохранением настроек.

## Первый запуск

1. Шестерёнка → выбери провайдера, вставь API-ключ, при необходимости поменяй модель.
2. Для работы с приватными репозиториями добавь GitHub-токен (fine-grained, права Contents: read/write).
3. Напиши задачу, например: «склонируй github.com/user/repo, найди где обрабатывается вход и добавь проверку пустого пароля».

## Ограничения текущей версии

- Команды `bash` выполняются в системном `sh` Android (toybox): есть `ls`, `cat`, `grep`, `sed`, `find`, `tar`, но нет python, node и gradle.
- Текст ответа показывается без разметки Markdown.
- Размер токенов считается приблизительно (~3 символа на токен), поэтому лимит контекста в настройках лучше ставить с запасом.
- Wake lock держится не дольше 2 часов за запуск сервиса; производители телефонов с агрессивной экономией батареи могут требовать исключения для приложения.
- `bash` не изолирован от файлов самого приложения: подтверждай команды, если не уверен.

## Дорожная карта

1. Встроенная Linux-среда (proot + rootfs), чтобы работали python, node, gcc, apt. Интерфейс `Shell` уже выделен под неё.
2. Foreground-сервис, чтобы длинные задачи не прерывались при сворачивании.
3. Потоковый вывод ответа и разметка Markdown.
4. Сохранение сессий, выбор рабочей папки/проектов.
5. Сборка Android-проектов из самого приложения.

## Структура

```
app/src/main/java/com/pocketcode/
  llm/     клиенты Anthropic и OpenAI-совместимых API
  tools/   инструменты агента (файлы, bash, git)
  agent/   цикл агента и системный промпт
  session/ хранилище сессий
  service/ foreground-сервис и уведомления
  ui/      экран чата, настройки, ViewModel
```
