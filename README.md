# PocketCode

Кодинг-агент в духе OpenCode / Claude Code / Codex, который работает **прямо на телефоне, без ПК**.
Пишешь задачу в чате, агент сам читает и правит файлы, запускает команды и Python, работает с git.

## Что умеет (v0.3)

**Агент**
- Цикл с инструментами: `read_file`, `write_file`, `edit_file`, `list_dir`, `grep`, `bash`, `python`, `git`
- Любая модель по API-ключу: Anthropic (Claude) или любой OpenAI-совместимый API (OpenAI, OpenRouter и т.д.)
- Потоковый вывод и Markdown в ответах (заголовки, списки, код, ссылки)
- Подтверждение опасных действий (запись, правка, команды, Python, git-изменения); можно отключить в настройках
- Автоматическое сжатие контекста в длинных сессиях: сначала сокращаются старые выводы инструментов, потом ранняя часть диалога заменяется сводкой

**Работа в фоне**
- Foreground-сервис с уведомлением и кнопкой «Стоп», wake lock; агент не прерывается при сворачивании и закрытии экрана
- Уведомления, когда нужно подтверждение или агент закончил

**Проекты и файлы**
- Проекты: у каждого своя рабочая папка и своя история чатов; создание, удаление, клонирование из GitHub
- Сессии сохраняются автоматически, есть экран «История»
- Хранилище на выбор: закрытая папка приложения или общая папка `PocketCode` в памяти телефона, которую видно в любом файловом менеджере (нужен доступ ко всем файлам)
- Добавление своих файлов и папок в проект через системный выбор файлов (работает в любом режиме хранилища)
- Подключение любой существующей папки телефона как проекта (агент работает с ней напрямую; удаление проекта файлы не стирает)
- Сохранение проекта в zip
- Встроенный просмотр и правка текстовых файлов проекта (кнопка «Файлы» в чате): навигация по папкам, создание и удаление файлов и папок

**Отладка устройств и root**
- ADB: экран «Устройства (ADB) и root» (сопряжение по коду, сохранённые устройства с подписями); агент получает инструмент `adb` через настоящий adb в Linux. Команды чтения выполняются сразу, остальное спрашивает
- Root: инструмент `root` (su) появляется, только если включён. Каждая root-команда всегда требует подтверждения, даже при «Выполнять без подтверждения»
- Автоподтверждение безопасных команд в оболочке Android не распространяется на пути вне папки проекта

**Среда запуска кода**
- Python 3.11 встроен в приложение (Chaquopy) и работает в отдельном процессе: зависшую программу можно остановить кнопкой «Стоп» или по таймауту. Доступна только стандартная библиотека, `pip` недоступен
- Linux (Alpine в proot): кнопка «Установить Linux» на экране проектов скачивает Alpine (~4 МБ). Тогда `bash` агента работает в настоящем Linux с `apk add python3 nodejs git build-base`; проект виден как `/work`. Без установки `bash` — системный `sh` Android (toybox)
- Git на чистой Java (JGit): clone, status, diff, add, commit, push, pull, log, branch, checkout

## Как собрать APK с телефона

1. Запушь изменения в `main` (или открой вкладку **Actions → Build APK → Run workflow**).
2. Дождись зелёной галочки.
3. Открой запуск, внизу в разделе **Artifacts** скачай `PocketCode-debug-apk`, распакуй zip и установи APK.

Все сборки подписаны одним ключом из `app/debug.keystore`, поэтому новая версия ставится поверх старой с сохранением настроек. APK стал заметно больше из-за встроенного Python.

## Первый запуск

1. Шестерёнка → провайдер, API-ключ, при необходимости модель и размер контекста.
2. Для приватных репозиториев добавь GitHub-токен (fine-grained, права Contents: read/write).
3. Нажми на название проекта вверху: там создание проектов, клонирование, добавление своих файлов и выбор хранилища.
4. Напиши задачу, например: «склонируй репозиторий и найди, где обрабатывается вход».

## Ограничения

- Linux-среда (proot) ни разу не запускалась на реальном телефоне; на некоторых прошивках proot может не стартовать. Нет systemd, демонов и интерактивного ввода.
- Нет Node.js и сторонних Python-пакетов.
- Git в общей папке `PocketCode` работает через файловую систему телефона без прав на исполнение и ссылки, поэтому возможны лишние отличия в режимах файлов.
- Размер токенов считается приблизительно (~3 символа на токен), лимит контекста в настройках лучше ставить с запасом.
- Wake lock держится не дольше 2 часов за запуск; на телефонах с агрессивной экономией батареи может понадобиться исключение для приложения.
- `bash` и Python не изолированы от файлов самого приложения: подтверждай команды, если не уверен.
- Доступ ко всем файлам (`MANAGE_EXTERNAL_STORAGE`) подходит для установки APK напрямую, но не для Google Play.

## Структура

```
app/src/main/java/com/pocketcode/
  llm/      клиенты Anthropic и OpenAI-совместимых API
  tools/    инструменты агента (файлы, bash, python, git)
  agent/    цикл агента, сжатие контекста, системный промпт
  python/   Python в отдельном процессе
  session/  хранилище сессий
  service/  foreground-сервис и уведомления
  ui/       чат, проекты, история, настройки, Markdown
app/src/main/python/runner.py   запуск программ агента
```

## Сторонний код

В `app/src/main/jniLibs` лежат готовые сборки PRoot (сам PRoot распространяется по GPL-2.0+) из https://github.com/green-green-avk/build-proot-android, версия 0.15. Лицензия скриптов сборки: `THIRD_PARTY_PROOT.txt`.
